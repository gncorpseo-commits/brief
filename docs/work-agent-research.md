# 업무 Agent — 자동화 가능 여부 & 구현 난이도 리서치

> 갱신: 2026-08-12  
> 범위: 재택알바·프리랜서 공개 공고 유형 표본 + 로컬 LLM(`brief` 생태계) 기준  
> 전제: CapNet 없이 **독립 LocalRuntime** 우선. 사람 확인(human_gate) 기본.

## 1. 한 줄 결론

| 우선 구현 | 이유 |
|-----------|------|
| 1. `reply` (`chat_reply` + `board_manage`) | 공고 물량 많음 · 구현 ★☆☆☆☆ · LLM만으로 MVP |
| 2. `entry` (`data_entry`) | 초보 알바 다수 · 구현 ★★☆☆☆ |
| 3. `caption` (`video_caption`) | 숏폼 공고의 공통 조각 · 구현 ★★★☆☆ |
| 보류(무거움) | 쇼핑몰 UI RPA full, 전화 실시간, CapCut UI 매크로 |

**효율 공식:** `공고빈도 × 자동화가치 ÷ 구현난이도`  
→ 1호는 `reply`, 영상 팩 진입은 `caption`(전체가 아닌 조각).

## 2. 난이도 척도

| 별 | 의미 | 대략 공수 (1인, MVP) | 스택 예 |
|----|------|----------------------|---------|
| ★☆☆☆☆ | 텍스트 I/O + 로컬 LLM | 3~7일 | FastAPI + Ollama |
| ★★☆☆☆ | 파일/시트 + 간단한 규칙 | 1~2주 | + openpyxl / CSV |
| ★★★☆☆ | 미디어 파이프라인 또는 공식 API | 2~4주 | + Whisper / FFmpeg |
| ★★★★☆ | 브라우저·앱 UI 자동화, 사이트별 셀렉터 | 1~2개월+ | Playwright 등 (유지비 큼) |
| ★★★★★ | 실시간 음성·멀티플랫폼 운영·권한 시스템 | 분기 단위 | 별도 제품급 |

부가 축:

- **유지비**: 사이트 UI 변경에 깨지면 높음  
- **규정 리스크**: AI 금지 공고, 전송·결제 무단 대행  
- **하드웨어**: 영상 렌더·STT는 노트북 GPU/RAM 민감

## 4. Agent 단위 구현 난이도 상세

### 4.1 `reply` (채팅·게시판) — ★☆☆☆☆

**공고에서 하는 일:** 쿠팡/쇼핑몰 상품문의, 배송·반품 안내, 채팅 CS, 매뉴얼 기반 답변.

| 단계 | 내용 | 난이도 |
|------|------|--------|
| MVP | 문의문 + 매뉴얼/FAQ → 답변 초안 | ★ |
| + | 톤·금칙어·회사 정책 프롬프트 | ★ |
| + | 문의 유형 분류 후 템플릿 선택 | ★★ |
| 비권장 초기 | 쇼핑몰 관리자 자동 로그인·자동 전송 | ★★★★ + 약관 |

**스택:** 로컬 LLM + 매뉴얼 텍스트/벡터 간단 검색.  
**막히는 지점:** 실시간 주문 DB 연동(없으면 “확인 후 안내” 플레이스홀더).  
**독립 실행:** 가능 (클립보드·사이드패널만으로도 가치).

### 4.2 `entry` (데이터 입력) — ★★☆☆☆

**공고:** 엑셀·워드·시트 반복 입력, 정확도·타자.

| 단계 | 내용 | 난이도 |
|------|------|--------|
| MVP | 비정형 텍스트/이미지OCR → 표 컬럼 매핑 제안 | ★★ |
| + | 검증 규칙(필수값, 형식, 중복) | ★★ |
| + | Google Sheet / Excel 파일 write | ★★ |
| 비권장 초기 | 임의 웹 폼 RPA | ★★★★ |

**스택:** LLM 구조화 출력 + openpyxl/CSV. OCR은 선택.  
**막히는 지점:** 업체마다 컬럼 스키마가 다름 → **사용자 스키마 프리셋** 필요.

### 4.3 `order_assist` (주문·배송) — ★★★☆☆~

| 단계 | 내용 | 난이도 |
|------|------|--------|
| MVP | 상태 설명 문구·체크리스트 생성 (데이터는 사람이 붙여넣기) | ★★ |
| + | 공식/내부 API 또는 export CSV 연동 | ★★★ |
| 높음 | 카페24·쿠팡 셀러센터 UI 자동화 | ★★★★ (유지비 큼) |
| 금지에 가깝 | 환불·결제·계정 권한 대행 full | ★★★★★ + 리스크 |

**권장:** 문구·분류·체크리스트만 Agent화. 실행 클릭은 사람.

### 4.4 `draft` / `translate` / `research` — ★☆☆☆☆

텍스트 생성계. `brief`와 엔진 공유 가능.  
**주의:** 바이럴 포스팅·플랫폼 스팸성 자동 게시는 제품 범위에서 제외하거나 publish 게이트 필수.

### 4.5 `phone_assist` — 스크립트 ★★ / 실시간 ★★★★★

| 수준 | 난이도 |
|------|--------|
| 통화 전 스크립트·예상 Q&A | ★★ |
| 통화 후 녹음 → 요약·티켓 | ★★★ (Whisper) |
| 실시간 음성 보조 | ★★★★★ |

초기에는 **스크립트·요약만**.

### 4.6 영상 팩

#### `caption` — ★★★☆☆  ← 영상 1호 권장

| 단계 | 내용 | 난이도 |
|------|------|--------|
| MVP | 음성 → 자막 텍스트 (Whisper 등) | ★★★ |
| + | 타이밍(SRT) + LLM 교정·강조 | ★★★ |
| + | 세로 영상용 줄바꿈·금칙어 | ★★ |

공고(아이보스·필름메이커스·당근 숏폼 등)에서 **컷+자막+BGM**이 반복 → 자막은 공통 조각.

#### `video_thumb` — ★★☆☆☆

키프레임 후보 + 문구 LLM. 상대적으로 가벼움.

#### `video_template` — ★★★☆☆ ~ ★★★★☆

| 접근 | 난이도 | 비고 |
|------|--------|------|
| FFmpeg 고정 템플릿(인트로·자막·BGM 슬롯) | ★★★ | 통제 가능 |
| CapCut 프로젝트 파일 조작 | ★★★★ | 포맷·버전 이슈 |
| CapCut GUI 매크로 | ★★★★★ | 깨지기 쉬움 |

공고는 CapCut 요구가 많음 → **제품은 “템플릿 결과물 mp4”를 주고, 툴은 FFmpeg부터**가 유지보수에 유리.

#### `video_short` (하이라이트·레퍼런스 복제) — ★★★★☆

침묵 제거·장면 후보는 ★★★, “레퍼런스와 같은 바이럴 감각”은 사람.  
**assist + export 전 확인**이 맞음.

### 4.7 `survey_label` — ★★☆☆☆ (+ 정책 ★★★)

기술은 쉽지만, 일부 공고는 **AI 사용 금지**.  
→ Agent에 “정책 모드: AI 금지면 비활성” 플래그 필요.

## 7. 구현 로드맵 (독립 Brief 생태계)

```text
Phase 0  디폴트 목록 JSON + 사용자 추가 UI
Phase 1  reply (chat/board) — Local LLM
Phase 2  entry — 시트 매핑
Phase 3  caption — Whisper + SRT + 교정
Phase 4  video_thumb / 간단 FFmpeg template
Phase 5  order 체크리스트·문구 (RPA 없음)
Phase 6  (선택) CapNet Runtime 어댑터
```

공통:

- 디폴트 목록 + 사용자 추가  
- 공고/`decompose` → 목록 항목 추천 체크  
- `human_gate` 없는 full 전송·결제는 기본 제공하지 않음

## 8. 리서치 출처 (유형)

- 알바몬 재택 목록 패턴 (CS·게시판·주문·바이럴 등)
- 아이보스 재택 숏폼 편집 공고 (CapCut, 레퍼런스, 건당, 24h)
- 필름메이커스·당근 등 숏폼 편집 공고 (컷·자막·BGM)
- 재택알바 종류·시급 가이드 (데이터입력·상담·번역·콘텐츠)
- 쇼핑몰 CS / 게시판 답변 실무 설명
- (참고) 해외 캡션·라벨링 공고의 AI 금지 조항

> 전수 통계 아님. 다음 정밀화: 공고 50건 CSV 태깅 → 빈도 재계산.
